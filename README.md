# LifeRebuild Landing Website

A mobile-first AMOLED landing page for selling the LifeRebuild 90-Day Habit & Focus app.

## Files

- `index.html` - landing page
- `style.css` - AMOLED theme styling
- `assets/life-rebuild-logo.png` - logo

## How to use

1. Upload the folder to GitHub Pages, Netlify, Vercel, or any static hosting.
2. Replace dummy screenshot cards in the `#screenshots` section with your real screenshots.
3. Replace the `Buy LifeRebuild Now` button link with your payment page URL.
4. Edit pricing, bonuses, and copy as needed.

## Recommended payment links

Use Gumroad, Razorpay Payment Pages, Instamojo, or any checkout page.
